О чем данный документ
=====================

Данный документ описывает реализацию аутентификации пользователей и авторизации приложений.

В версии 1.0 данное API представляет собой протокол [OAuth 2.0 Framework]. На первых порах будет достаточно реализации передачи логина/пароля в открытом виде, так как пользоваться будут только доверенные приложения Инетры.

Пользователи должны быть разделены на две группы:

- анонимные, без владения паролем. В качестве логина такого пользователя обычно выступает идентификатор приложения.
- с паспортом CN.ru, владеющие паролем. В качестве логина и пароля пользователя фигурируют логин и пароль Паспорта CN.ru, соответственно.

Соответственно токены доступа могут быть двух видов:

- анонимные (у анонимных пользователей);
- персональные (у пользователей с Паспортом).

Токены доступа на данный момент могут быть постоянными, о переходе на короткоживущие периодически обновляемые токены будет сообщено дополнительно.

Также отдельным Flow должен быть реализован запрос цифрового PIN–кода длиной в 9 знаков, который живет не более 15 минут. Аутентифицированный пользователь (в том числе, анонимный) с помощью такого временного токена доступа имеет возможность аутентификации на другом устройстве без ввода логина/пароля.

Расположение API
================

Расположение данного API фиксировано: `https://api.cn.ru/auth/` (внимание: доступно только по HTTPS), но также должно присутствовать в Регистратуре в списке сервисов, предоставляемых Инетрой.

Отдельные потоки аутентификации могут располагаться в дочерних URI описанного выше.

[OAuth 2.0 Framework]: http://tools.ietf.org/html/rfc6749

Описание
========

API реализует интерфейс для получения информации о каналах телевидения, а также их расписания. Идентификаторы сущностей (канал, телепередача, выпуск телепередачи) должны быть использованы другими поставщиками данных для расширения:

- списка каналов провайдера (добавление логотипа канала, названия и другой информации)
- списка записей выпусков телепередач

Формат ответа зависит от суффикса переданного метода. Поддерживаются следующие суффиксы:

- `.json` — JSON
- `.protobuf` — Google Protocol Buffers

Все даты передаются в UNIX time, в часовом поясе GMT.

Возрастные ограничения
----------------------

Возрастное ограничение — это возраст (в годах), с которого можно потреблять медиа–контент без вреда для психики человека. Он определен для:

- выпуска телепередачи;
- телепередачи;
- канала.

Возрастные ограничения могут быть указаны вручную или получены автоматически, на основании возрастных ограничений элементов, из которых состоит сущность. При автоматическом вычислении возрастного ограничения результат является максимумом возрастных ограничений элементов. Таким образом, для канала, возрастные ограничения телепередач которого колеблются от 0 до 18 лет, возрастным ограничением будет 18 лет.

Методы
======

## Получение списка каналов

Запрос: `channels`.

 параметр  | формат                           | значение по умолчанию | смысл
-----------|----------------------------------|-----------------------|-------
`logo_size`| `WIDTHxHEIGHT`                   | отсутствует           | предпочтительное разрешение логотипа канала
`filter`   | идентификаторы каналов через `,` | пусто                 | список идентификаторов запрашиваемых каналов
`detailed` | `true` или `false`               | `false`               | передача полной информации о каналах

Формат ответа: сообщение `ChannelsList`.

Отсутствие параметра `filter` означает передачу информации обо всех каналах.

В данном методе гарантируется передача (при `detailed=false`):

- названия телеканала
- идентификатора телеканала (в том числе строкового)
- URL логотипа канала
- возрастного ограничения
- наличие расписания для канала

## Получение расписания для канала

Запрос: `schedule`.

 параметр | формат | значение
----------|--------|----------
`channel` | число  | идентификатор канала
`from`    | число  | время начала запрашиваемого расписания
`to`      | число  | время окончания запрашиваемого расписания

Формат ответа: сообщение `Schedule`.

## Получение информации о выпуске телепередачи по его идентификатору

Запрос: `telecastInfo`.

 параметр | значение
----------|----------
`telecast`| идентификатор выпуска телепередачи

Формат ответа: сообщение `Schedule`.

# Описания форматов способом Google Protocol Buffers

## TVShow — Телепередача

	message TVShow {
	  optional uint32 id = 1;
	  optional string title = 2;
	  optional string description = 3;
	  repeated Channel channels = 4;
	  optional uint32 ageRestriction = 5;
	  optional string URL = 6;
	}
	 
	message TVShowList {
	  repeated TVShow tvShows = 1;
	}

Замечания:

- `id` — идентификатор телепередачи
- `title` — название телепередачи
- `description` — описание телепередачи
- `channels` — список каналов, на которых выходят выпуски телепередачи
- `ageRestriction` — возрастное ограничение телепередачи
- `URL` — адрес страницы телепередачи в интернете

## Telecast — Описание выпуска телепередачи

	message Telecast {
	  optional uint64 id = 1;
	  optional string title = 2;
	  optional string description = 3;
	  optional uint64 date = 4;
	  optional uint32 duration = 5;
	 
	  message TelecastImage {
	    enum Profile {
	      IMAGE = 0;
	      PREVIEW = 1;
	      MAIN = 2;
	    }
	    optional Profile profile = 1;
	    optional uint32 width = 2;
	    optional uint32 height = 3;
	    optional string location = 4;
	  }
	 
	  repeated TelecastImage telecastImages = 7;
	  optional uint32 tvShowId = 10;
	  optional uint32 channelId = 11;
	  optional uint32 ageRestriction = 12;
	}

Замечания:

- `id` — идентификатор выпуска телепередачи
- `title` — название выпуска
- `description` — описание выпуска
- `date` — время выхода выпуска
- `duration` — продолжительность (в секундах)
- `telecastImages` — изображения для телепередачи
- `tvShowId` — идентификатор телепередачи
- `channel` — идентификатор канала выпуска телепередачи
- `ageRestriction` — возрастное ограничение для выпуска телепередачи

## Channel — Описание канала

	message Channel {
      message ScheduleInfo {
        optional uint64 from = 1;
        optional uint64 to = 2;
      }
	  optional uint32 channelId = 1;
	  optional string title = 2;
	  optional string description = 3;
	  optional string logoURL = 4;
	  optional string URL = 5;
	  optional Telecast currentTelecast = 6;
	  optional string alias = 7;
	  optional uint32 ageRestriction = 8;
	  optional ScheduleInfo scheduleInfo = 9;
	}

Замечания:

- `channelId` — числовой идентификатор канала
- `title` — название
- `description` — описание канала
- `logoURL` — URL логотипа канала
- `URL` — ссылка на сайт канала в интернете
- `currentTelecast` — текущая телепередача
- `alias` — строковый идентификатор канала
- `ageRestriction` — возрастное ограничение для канала
- `scheduleInfo` — информация о временном периоде, для которого доступно расписание телепередач канала

## Schedule — Расписание для канала

	message Schedule {
	  optional string channelId = 1;
	 
	  repeated Telecast schedule = 2;
	}

## ChannelsList — Список каналов

	message ChannelsList {
	  repeated Channel channels = 1;
	}

Изменения в версии 2.1
----------------------

1. Добавлен признак доступности эфира и записей телепередач канала.
2. Метод `/list` помечен как "устаревший". В версии 3.0 TV API данного метода *не будет*.
3. Добавлена сущность "Телепередача".

5. Добавлены параметры "Возрастные ограничения" для канала, передачи и выпуска телепередачи.
6. Добавлен параметр наличия расписания в сообщении `Channel`.

Изменения в версии 2.0

1. Изменения в общих параметрах:

2. В XSPF оставлен только один метод — list.xspf, для клиентов, не поддерживающих API. Все остальное переведено на JSON, XML и Protocol Buffers.
3. Убран метод договора оферты.
4. Убран метод получения дат с наличествующем расписанием для канала.
5. Добавлен метод получения описания о конкретном канале.
6. Добавлен метод получения информации о канале по идентификатору выпуска телепередачи.
7. Добавлена возможность получения расписания передач канала для нескольких дат.

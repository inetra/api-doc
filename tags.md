# Общая информация

Данный сервис предназначен для получения тагов peers.tv внешними сервисами.

## Расположение API

Корневой адрес API — `https://api.peers.tv/tags/`. Формат ответа JSON.

## Поиск тага по имени <a id="ajax"></a>
Запрос отправляется методом GET.  
Производит поиск тага по названию. Название тага (или часть названия) передается параметром "q".

Ответ:

    [{value: Integer, title: String}]

Возвращаемые параметры:
* value - id тага
* title - название тага

Пример:

    Запрос: https://api.peers.tv/tags/ajax?q=карат
    Ответ: [{"value":104949699,"title":"\u041a\u0430\u0440\u0430\u0442\u0435"}]

## Поиск по id тага <a id="ajaxid"></a>
Запрос отправляется методом GET.  
Производит поиск тага по id. Id передается параметром "id"

Ответ:

    [{value: Integer, title: String}]

Возвращаемые параметры:
* value - id тага
* title - название тага


Пример:

    Запрос: https://api.peers.tv/tags/ajaxid?id=104949699
    Ответ: [{"value":104949699,"title":"\u041a\u0430\u0440\u0430\u0442\u0435"}]
